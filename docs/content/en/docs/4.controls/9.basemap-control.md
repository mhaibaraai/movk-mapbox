## Introduction

`MaplibreBasemapControl` is a controlled component: it only handles selection, emitting the selected item's `style` through `v-model` without calling `setStyle`. Bind the same value to the `options.style` of `MaplibreMap`, and the map switches the style and rebuilds overlay layers automatically. The style lives in one place, so the control and the map never disagree.

Generate a full style for Tianditu basemaps with [`tiandituStyle()`](/docs/extensions/tianditu), and switch it together with vector styles such as OpenFreeMap in the same `items` list.

::tip
After switching basemaps, the visibility and opacity of each [`MaplibreLayerGroup`](/docs/core/layer-group), including basemap layers adopted through `styleLayers`, are restored on the new style automatically.
::
