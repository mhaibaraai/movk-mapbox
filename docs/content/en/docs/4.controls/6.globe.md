## Introduction

`MaplibreGlobeControl` provides a button that toggles the projection between `globe` and `mercator`; `position` sets the dock corner.

::note
The control only recognizes string projections: an interpolation expression is treated as "not mercator" and switched back to mercator, so avoid combining them. When used with `MaplibreProjection`, the toggled result is overridden by the component value after a style reload or props change.
::
