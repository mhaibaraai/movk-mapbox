## Introduction

`MaplibreGradientBuilding` renders 3D buildings from the building data given by `source` / `sourceLayer`, interpolating colors between `stops` breakpoints by height; `opacity` / `minzoom` control transparency and the starting zoom level. Requires a tilted view and zoom ≥ `minzoom` (default 15).
