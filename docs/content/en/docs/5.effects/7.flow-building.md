## Introduction

`MaplibreFlowBuilding` renders 3D buildings from the building data given by `source` / `sourceLayer`: gradient shading with a highlight band that cycles along building height; `color` / `flowColor` / `duration` / `bandHeight` / `maxHeight` control the appearance and timing. Requires a tilted view and zoom ≥ `minzoom` (default 15).
