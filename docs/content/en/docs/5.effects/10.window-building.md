## Introduction

`MaplibreWindowBuilding` renders 3D buildings from the building data given by `source` / `sourceLayer`, applying a procedurally generated window-grid texture as `fill-extrusion-pattern`; `rows` / `cols` / `litColor` / `darkColor` / `litRatio` / `seed` control the window appearance. Requires a tilted view and zoom ≥ `minzoom` (default 15).
