## Introduction

`MaplibreBuildingLayer` extrudes building polygons from `source` (plus `sourceLayer` for vector tiles) into 3D buildings. Height expressions are built in; `color`, `opacity`, and `minzoom` are available as convenience props. Height fields default to the OpenMapTiles `render_height` / `render_min_height` and can be changed with `heightProperty` / `baseProperty`.

::note{color="warning"}
A source with building height properties is required (the examples use the `openmaptiles` source bundled with OpenFreeMap styles). A non-zero map `pitch` and sufficient `zoom` (default minzoom 15) are required to see buildings.
::
