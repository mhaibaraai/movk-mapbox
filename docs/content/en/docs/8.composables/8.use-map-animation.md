## Introduction

`useMapAnimation` is a map frame-animation primitive built on `useRafFn` (automatically stopped when the component unmounts). It invokes the `frame` callback only after the map's first `load` event and while the style is parsed. The second argument to the callback is the elapsed milliseconds since the animation started. Animated effect components and frame-driven images all share this primitive. Returns `pause`, `resume`, and `isActive` to control the animation state.

::note
When used outside a `<MaplibreMap>` subtree, specify the target map via `options.mapId`. The callback runs every frame — avoid creating new objects or doing heavy computation inside it.
::

::tip
No frames run before the first `load`, so per-frame style changes cannot delay the `load` event. After that, gating only checks whether the style has been parsed and does not wait for tiles or sources to load, so animations keep running while panning, zooming, or calling `setData` every frame. For time-driven scenarios such as track playback, accumulate `deltaMs` instead of tracking the previous frame time yourself.
::

## API

### `useMapAnimation()`{lang="ts-type"}

Creates a frame animation loop.

::field-group
  ::field{name="frame" type="(map: Map, elapsedMs: number, deltaMs: number) => void" required}
  Per-frame callback; `elapsedMs` is the elapsed milliseconds since the animation started, `deltaMs` is the milliseconds since the previous frame.
  ::
  ::field{name="options.mapId" type="string"}
  Target map id; required when used outside a `<MaplibreMap>` subtree.
  ::
  ::field{name="options.immediate" type="boolean"}
  Start immediately after creation, defaults to `true`.
  ::
::

Returns `UseMapAnimationReturn`:

::field-group
  ::field{name="pause" type="() => void"}
  Pauses the animation.
  ::
  ::field{name="resume" type="() => void"}
  Resumes the animation.
  ::
  ::field{name="isActive" type="Readonly<Ref<boolean>>"}
  Whether the animation is currently running.
  ::
::
