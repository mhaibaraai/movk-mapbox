## Introduction

`useMapSync` keeps the cameras of several maps aligned: when any map moves, its `center`, `zoom`, `bearing` and `pitch` are copied to the others. It takes effect once every map instance is ready, aligns the others to the first map in the list at that point, and unbinds automatically when the calling scope is disposed.

::note
Referencing a map by id requires `map-id` on that `MaplibreMap`; maps mounted after the call still work. For swipe comparison use [`MaplibreCompare`](/docs/extensions/compare) directly instead of calling this yourself.
::

## API

### `useMapSync()`{lang="ts-type"}

::field-group
  ::field{name="maps" type="MaybeRefOrGetter<MapSyncTarget[]>" required}
  Maps to sync: `map-id` strings or map contexts (such as the return value of `useMap()`); the binding is rebuilt when the list changes.
  ::
  ::field{name="options.enabled" type="MaybeRefOrGetter<boolean>"}
  Whether syncing is enabled, `true` by default; `false` unbinds, and turning it back on realigns the others to the first map.
  ::
::
