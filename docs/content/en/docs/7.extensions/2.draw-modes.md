## Introduction

`movkDrawModes` returns a set of configured terra-draw mode instances: a select mode (vertex editing for points, lines and polygons; whole-feature dragging for regular shapes) plus every built-in draw mode, all styled by [drawThemeStyles](/docs/extensions/draw-theme). [MaplibreDrawControl](/docs/extensions/draw) uses it when `modes` is not provided; switch modes with `changeMode` or `v-model:mode`.

Auto-imported from `@movk/maplibre` — no manual import needed.

::note
When auto-import is not enabled (unplugin disabled, or in plain `.ts` scripts and tests), import it explicitly from `@movk/maplibre/draw-modes`. Each call returns new instances; mode instances cannot be shared between controls.
::

## API

### `movkDrawModes()`{lang="ts-type"}

Returns `DrawMode[]` in the order `select` / `point` / `linestring` / `polygon` / `rectangle` / `circle` / `ellipse` / `sector`. To customize a single mode, construct terra-draw mode instances directly and pass them to the control's `modes`.

::field-group
  ::field{name="options.theme" type="DrawThemeOptions"}
  Draw theme; same fields as [drawThemeStyles](/docs/extensions/draw-theme).
  ::
::

The same entry also exports `DRAW_MODE_NAMES`, a constant with the draw mode names (excluding `select`).
