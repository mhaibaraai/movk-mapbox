## Introduction

`drawThemeStyles` generates terra-draw `styles` objects for each mode (keyed by mode name) from theme options. Inactive colors read the feature's `properties.color` first and fall back to the theme color, so you can color features individually with `setFeatureProperty(id, 'color', value)`; selected states and drawing guidance points use the active color.

Auto-imported from `@movk/maplibre` — no manual import needed. You rarely need to call it directly: pass `theme` to [MaplibreDrawControl](/docs/extensions/draw), and use this function only when constructing terra-draw modes yourself.

## Usage

Switch the primary color to generate theme styles (a preset polygon renders immediately):

::component-example
---
name: DrawThemeExample
prettier: true
collapse: true
clientOnly: true
options:
  - name: color
    label: color
    default: '#8b5cf6'
    items:
      - '#8b5cf6'
      - '#3b82f6'
      - '#10b981'
      - '#f43f5e'
---
::

## API

### `drawThemeStyles()`{lang="ts-type"}

Takes `options: DrawThemeOptions` (defaults apply when omitted) and returns `DrawThemeStyles` with styles for `select` / `point` / `linestring` / `polygon` / `rectangle` / `circle` / `ellipse` / `sector`.

::field-group
  ::field{name="color" type="HexColor"}
  Primary color for inactive state. Defaults to `#3b82f6`.
  ::
  ::field{name="activeColor" type="HexColor"}
  Primary color for active state (drawing guidance points / selected). Defaults to `#f59e0b`.
  ::
  ::field{name="fillOpacity" type="number"}
  Polygon fill opacity. Defaults to `0.1`.
  ::
  ::field{name="lineWidth" type="number"}
  Line width. Defaults to `2`.
  ::
  ::field{name="vertexRadius" type="number"}
  Vertex circle radius. Defaults to `5`.
  ::
::

::note
terra-draw only accepts hex colors (such as `#3b82f6`), not other formats like `rgb()`.
::
