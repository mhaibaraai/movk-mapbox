## 简介

`useMapSync` 让多张地图的相机保持一致：任一地图移动时，把 `center`、`zoom`、`bearing`、`pitch` 同步到其余地图。全部地图实例就绪后才生效，生效时以列表中第一张地图的相机对齐其余地图；随调用方作用域销毁自动解绑。

::note
按 id 引用时需为对应 `MaplibreMap` 设置 `map-id`；地图晚于调用挂载也能生效。卷帘对比场景直接使用 [`MaplibreCompare`](/docs/extensions/compare)，无需手动调用。
::

## API

### `useMapSync()`{lang="ts-type"}

::field-group
  ::field{name="maps" type="MaybeRefOrGetter<MapSyncTarget[]>" required}
  参与联动的地图：`map-id` 字符串或地图上下文（如 `useMap()` 的返回值）；列表变化时重新绑定。
  ::
  ::field{name="options.enabled" type="MaybeRefOrGetter<boolean>"}
  是否启用联动，默认 `true`；置 `false` 解绑，恢复时以首图相机重新对齐。
  ::
::
