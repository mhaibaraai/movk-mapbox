## 简介

`MaplibreGlobeControl` 提供投影切换按钮，点击在 `globe` 与 `mercator` 间切换；`position` 指定停靠角。

::note
控件只识别字符串投影：当前投影为插值表达式时会被视为「非 mercator」并切回 mercator，此场景不建议搭配使用。与 `MaplibreProjection` 并用时，控件切换结果会在样式重载或组件 props 变化后被组件值覆盖。
::
