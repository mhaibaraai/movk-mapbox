## 简介

`MaplibreControl` 把插槽内容挂到 maplibre 的控件槽位（四角停靠，与内置控件一起排列），内容仍在 Vue 组件树内，可以直接使用响应式状态和注入的地图上下文。`MaplibreLayerControl`、`MaplibreBasemapControl`、`MaplibreLegend` 都基于它实现。

- **可折叠**：设置 `collapsible` 后收起为 `#trigger` 插槽提供的图标按钮，点击展开；面板右上角的关闭按钮或 Esc 收起，`dismissible` 为真时点击控件外部也会收起。
- **状态**：`v-model:open` 可受控，不绑定时组件自行维护。

::note
控件内的按钮会受 maplibre 控件组样式（`.maplibregl-ctrl-group button` 固定 29px 方块）影响，自定义按钮样式时请用不低于它的选择器，或设置 `:group="false"` 去掉控件组样式。
::
