## 简介

`MaplibreBuildingLayer` 把 `source`（及矢量瓦片的 `sourceLayer`）中的建筑面挤出为 3D 建筑，封装好高度表达式，开放 `color` / `opacity` / `minzoom` 快捷设置。高度字段默认对齐 OpenMapTiles 规范的 `render_height` / `render_min_height`，可经 `heightProperty` / `baseProperty` 调整。

::note{color="warning"}
需提供含建筑高度属性的数据源（示例使用 OpenFreeMap 样式自带的 `openmaptiles` 源）；需地图 `pitch` 与较高 `zoom`（默认 minzoom 15）才能看到建筑。
::
