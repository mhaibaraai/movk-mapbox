## 简介

`drawThemeStyles` 依据主题选项生成 terra-draw 各模式的 `styles` 对象（键为模式名）。非激活态颜色优先读取要素 `properties.color`，缺省回退主题色，因此可经 `setFeatureProperty(id, 'color', value)` 按要素着色；选中态与绘制辅助点统一使用激活色。

从 `@movk/maplibre` 自动导入，无需手写 import。一般无需直接调用：给 [MaplibreDrawControl](/docs/extensions/draw) 传 `theme` 即可，自行构造 terra-draw 模式时再用它取样式。

## 用法

切换主色生成主题样式（预置多边形即时呈现）：

::component-example
---
name: DrawThemeExample
prettier: true
collapse: true
clientOnly: true
options:
  - name: color
    label: color
    default: '#8b5cf6'
    items:
      - '#8b5cf6'
      - '#3b82f6'
      - '#10b981'
      - '#f43f5e'
---
::

## API

### `drawThemeStyles()`{lang="ts-type"}

入参 `options: DrawThemeOptions`（省略用默认值），返回 `DrawThemeStyles`，包含 `select` / `point` / `linestring` / `polygon` / `rectangle` / `circle` / `ellipse` / `sector` 各模式的样式。

::field-group
  ::field{name="color" type="HexColor"}
  非激活态主色，默认 `#3b82f6`。
  ::
  ::field{name="activeColor" type="HexColor"}
  激活态（绘制辅助点 / 选中）主色，默认 `#f59e0b`。
  ::
  ::field{name="fillOpacity" type="number"}
  多边形填充不透明度，默认 `0.1`。
  ::
  ::field{name="lineWidth" type="number"}
  线宽，默认 `2`。
  ::
  ::field{name="vertexRadius" type="number"}
  顶点圆半径，默认 `5`。
  ::
::

::note
terra-draw 只接受十六进制颜色（如 `#3b82f6`），不支持 `rgb()` 等其他格式。
::
