## 简介

`movkDrawModes` 返回一组配置好的 terra-draw 模式实例：选择模式（点线面可编辑顶点，规则图形可整体拖拽）加全部内置绘制模式，并按 [drawThemeStyles](/docs/extensions/draw-theme) 统一着色。[MaplibreDrawControl](/docs/extensions/draw) 未传 `modes` 时即使用它，经 `changeMode` 或 `v-model:mode` 切换。

从 `@movk/maplibre` 自动导入，无需手写 import。

::note
未启用自动导入时（关闭 unplugin、或在纯 `.ts` 脚本与测试中使用），可从 `@movk/maplibre/draw-modes` 显式导入。每次调用返回新实例，模式实例不能在多个控件间共享。
::

## API

### `movkDrawModes()`{lang="ts-type"}

返回 `DrawMode[]`，依次为 `select` / `point` / `linestring` / `polygon` / `rectangle` / `circle` / `ellipse` / `sector`。需要自定义单个模式时，可直接从 `terra-draw` 构造模式实例并传给控件的 `modes`。

::field-group
  ::field{name="options.theme" type="DrawThemeOptions"}
  绘制主题，字段同 [drawThemeStyles](/docs/extensions/draw-theme)。
  ::
::

同一入口还导出 `DRAW_MODE_NAMES`（不含 `select` 的绘制模式名常量）。
