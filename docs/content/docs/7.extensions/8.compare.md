## 简介

`MaplibreCompare` 把 `#before`、`#after` 两个插槽中的 `MaplibreMap` 叠放，后图按分隔条位置裁切，拖动分隔条即可对照两张地图。两张地图的相机自动联动（基于 [`useMapSync`](/docs/composables/use-map-sync)），插槽内的地图无需设置 `map-id`。分隔条支持指针拖拽与键盘操作（方向键、`Home`、`End`）。

::note
后图叠在前图之上并按分隔条裁切，放在后图内的控件只在其露出区域可见，建议停靠在 `vertical` 时的右侧角或 `horizontal` 时的下侧角。
::
