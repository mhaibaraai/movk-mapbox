## 简介

`MaplibreTiandituLayer` 以天地图 WMTS 瓦片作底图：`layer` 选类型（`vec` 矢量 / `img` 影像 / `ter` 地形，及注记 `cva`/`cia`/`cta`），`annotation` 叠加对应注记层，`tk` 缺省时回退运行时配置 `maplibre.tk`。

::note
天地图坐标系为 WGS84（CGCS2000），自有 WGS84 数据可直接叠加，无需 [坐标转换](/docs/extensions/coordinate)；只有高德 / 腾讯（GCJ02）、百度（BD09）的数据叠加时才需要先转换。
::

## 用法

切换 `layer` 查看矢量/影像/地形底图（均叠加注记）：

::component-example
---
name: TiandituLayerExample
prettier: true
options:
  - name: layer
    label: layer
    default: vec
    items:
      - vec
      - img
      - ter
  - name: annotation
    label: annotation
    default: true
    items:
      - true
      - false
---
::

## 作为底图样式

`tiandituStyle(layer, { annotation, tk })` 把天地图底图与注记组装成完整的样式对象，可以直接作为 `MaplibreMap` 的 `options.style`，或放进 [MaplibreBasemapControl](/docs/controls/basemap-control) 与矢量样式一起切换。样式中的 `glyphs` 取自运行时配置，便于叠加文字图层。

```ts
import { tiandituStyle } from '@movk/maplibre/utils/tianditu'

const imagery = tiandituStyle('img', { annotation: true })
```

::tip
需要在其他底图上叠加天地图时使用 `MaplibreTiandituLayer`；需要把天地图作为可切换的底图时使用 `tiandituStyle`。
::
