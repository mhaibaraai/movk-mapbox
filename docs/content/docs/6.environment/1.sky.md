## 简介

`MaplibreSky` 调用 `setSky` 设置天空效果，`options` 透传 MapLibre sky 规格（`sky-color` / `horizon-color` / `fog-color` / `sky-horizon-blend` / `horizon-fog-blend` / `fog-ground-blend` / `atmosphere-blend`），省略则使用规格默认值；卸载时恢复默认。大俯仰角下地平线与雾化最明显，`atmosphere-blend` 作用于 globe 投影的大气光晕。
